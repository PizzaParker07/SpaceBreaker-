Yörüngede hâlâ **düşüyorsundur**; ama yana öyle hızlı gidersin ki zemin altından kıvrılıp uzaklaşır.

| | |
|---|---|
| Alçak Dünya yörüngesi hızı | ≈ 7,8 km/s |
| Fırlatma maliyeti (kayıplarla) | ≈ 9,4 km/s Δv |
| Ay'a geçiş | ≈ 4,0 km/s Δv |

> [!NOTE]
> Aradaki fark **sürtünme** ve **yerçekimi kayıplarıdır**: atmosferden geçerken ve dik tırmanırken harcanan Δv.
