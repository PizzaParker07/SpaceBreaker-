The keys below are **your** keys; change them in the options and this page follows.

| What it does | Key |
|---|---|
| Open the research tree | {key key.spacebreaker.research} |
| Open the field guide | {key key.spacebreaker.guide} |
| [Launch](first_flight#launch) / abort the countdown | {key key.spacebreaker.launch} |
| Star map (in orbit) | {key key.spacebreaker.star_map} |
| Maneuvering unit: up | {key key.jump} |
| Maneuvering unit: down | {key key.sneak} |
| Helmet lamps: wide / long beam (40 blocks, for lava tubes and cold traps) | {key key.spacebreaker.helmet_lamp} |

## Aboard a rocket
| What it does | Key |
|---|---|
| Orbit around the rocket | mouse |
| Zoom in / out | mouse wheel |
| Cockpit window | {key key.togglePerspective} |
| Start / abort the countdown | {key key.spacebreaker.launch} |
| Star map (in orbit) | {key key.spacebreaker.star_map} |
| Get out | {key key.sneak} |
→ [Flight and Navigation](navigation)

## With the mouse
- **Gold sun visor:** hold {key key.sneak} and press {key key.use} with the {item spacebreaker:eva_helmet} in hand.
- **Fitting a tank:** {key key.use} with an {item spacebreaker:oxygen_tank} while wearing an {item spacebreaker:eva_chestplate}.
- **Putting the rocket on the pad:** {key key.use} the {item spacebreaker:rocket} on the middle of the flame trench.
- **Boarding:** {key key.use} the rocket. Press {key key.sneak} to get out.
- **Taking the rocket down:** hold {key key.sneak} and hit it.
- **Pipe pull mode:** hold {key key.sneak} and {key key.use} the end of a pipe.
