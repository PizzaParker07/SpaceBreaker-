# Terimler (TR ↔ EN)

Saha rehberinde ve oyun metinlerinde aynı şey için hep aynı terim kullanılır. Eşya ve blok adları dil
dosyasındaki adlardır; rehber düz metinde de onları kullanır. Yeni metin yazarken önce bu listeye bak.

## Genel

| Türkçe | English | Not |

| saha rehberi | field guide | Kitabın adı "Spacebreaker Saha Rehberi" |
| bölüm / konu | chapter / topic | İçindekilerde konu → bölüm |
| harabe | ruin | "zindan" kullanılmaz |
| teknoloji | technology | |
| teknoloji ağacı / araştırma ağacı | tech tree / research tree | |
| teknoloji diski | tech disk | |
