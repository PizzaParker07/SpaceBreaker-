# Bulutlarda Yaşam ve Harabeler

*İlgili araştırma: Gezegenler Arası Transfer*

**Canlı:** Bulut Medüzü

### Bulut Medüzü
Hafif gaz keseleriyle süzülür ve havadan kükürt süzer. Zararsızdır. **Kaldırma Gazı Kesesi** bırakır: kullanınca 30 saniye yavaş düşersin.

### Asit Vatozu
Geniş kavislerle süzülür. Ona dokunma: zırhı aşındıran **asit püskürtür**. Kükürt ve deri bırakır.

### Asit kaplaması

**Floropolimer Kaplama**

Herhangi bir zırh parçasını ve bir **Floropolimer Kaplama** öğesini üretim ızgarasında birleştir: zırh **aside dayanıklı** olur.

### Yüzen platformlar

**Hafif Kompozit Panel** · **Aerojel** · **Balon Kumaşı**

Hafif kompozit paneller ve aerojel, solunabilir hava katmanında yüzen platformlar kurmanı sağlar.

|   |   |
|---|---|
| Plastik Levha | Alüminyum Levha |
| Alüminyum Levha | Plastik Levha |

→ **Hafif Kompozit Panel ×4** (Çalışma Masası)

### Aerostat platform kiti

**Aerostat Platform Kiti**

Bulutlarda bir eve en kısa yol. **Aerostat Platform Kiti**'ni **yaşanabilir bulut kuşağında** (yaklaşık 1 bar ve oda sıcaklığı; bulut tabanından bulut tepelerinin ~30 blok üstüne kadar) kullan: yüzen bir üs şişer. **9×9** kompozit güverte, kapılı korkuluk, halatlar, bir fener ve tepede kaldırma gazı zarfı.

|   |   |   |
|---|---|---|
| Balon Kumaşı | Kaldırma Gazı Kesesi | Balon Kumaşı |
| Hafif Kompozit Panel | Zincir | Hafif Kompozit Panel |
| Balon Kumaşı | Kaldırma Gazı Kesesi | Balon Kumaşı |

→ **Aerostat Platform Kiti** (Çalışma Masası)

> [!WARNING]
> Yalnızca boş havaya yerleşir. Kuşağın altında zarf pişer, üstünde ise kaldırmaz: orada çalışmaz.

> [!TIP]
> Bulut Medüzlerini kaldırma gazı keseleri için avla, kiti üret ve üssünü bulutlarda kur. Asit kaplamalı zırh giy.

### Venüs İniş Sondası

**Venüs İniş Sondası**

Yüzey (464 °C, 92 bar) insana kapalıdır. **Venüs İniş Sondası**'nı bulut katmanından, örneğin aerostat üssünden bırak: paraşütle iner, yüzeye değince sana **2 Venüs numunesi** ve **Sonda İnişi** verisi gönderir, sonra yaklaşık bir dakika içinde ısıdan susar.

|   |   |   |
|---|---|---|
|   | Balon Kumaşı |   |
| Aerojel | Temel Devre Kartı | Aerojel |
| Tungsten Külçe | Tungsten Külçe | Tungsten Külçe |

→ **Venüs İniş Sondası** (Çalışma Masası)

> [!WARNING]
> Yalnızca Venüs'te ve bulut katmanından (y ≥ 175) bırakılır; daha alçakta ya da başka yerde harcanmaz. Numuneler envanterine gelir, doluysa ayağının dibine düşer. Sonda indiğinde oyunda değilsen numuneler gelmez.

> [!TIP]
> Bulut Medüzü → aerostat kiti → bulutta üs → iniş sondası → Venüs numuneleri → Venüs teknolojileri.

> [!NOTE]
> Bulut tepelerinin üstünde terk edilmiş bir araştırma balonu süzülür. Laboratuvarında hâlâ teknoloji diskleri var; Asit Vatozları onları korur.

### Balonun bulmacaları
- Üç **gaz vanası** var; gondol kapısını yalnızca **kükürt sarısı** işaretli olan açar.
- İskelede **düşen döşeme** tuzağı var; altındaki ağ seni yakalar.

**Creature:** Cloud Jelly

### Cloud Jelly
Drifts on sacs of light gas and sieves sulfur from the air. Harmless. It drops a **Lift Gas Sac**: use it to fall slowly for 30 seconds.

### Acid Ray
Glides in wide curves. Leave it alone: it **sprays acid** that eats into armour. Drops sulfur and leather.

### Acid coating

**Fluoropolymer Coating**

Put any armour piece and an **Fluoropolymer Coating** together in a crafting grid: the armour becomes **acid-proof**.

### Floating platforms

**Light Composite Panel** · **Aerogel** · **Envelope Fabric**

Light composite panels and aerogel let you build platforms that float in the breathable-air layer.

|   |   |
|---|---|
| Plastic Sheet | Aluminum Plate |
| Aluminum Plate | Plastic Sheet |

→ **Light Composite Panel ×4** (Crafting Table)

### Aerostat platform kit

**Aerostat Platform Kit**

The quickest way to a home in the clouds. Use an **Aerostat Platform Kit** in the **habitable cloud band** (about 1 bar and room temperature, from the cloud base to about 30 blocks above the cloud tops) and it inflates a floating base: a **9×9** composite deck with a gated railing, rigging, a lantern and a lift-gas envelope overhead.

|   |   |   |
|---|---|---|
| Envelope Fabric | Lift Gas Sac | Envelope Fabric |
| Light Composite Panel | Chain | Light Composite Panel |
| Envelope Fabric | Lift Gas Sac | Envelope Fabric |

→ **Aerostat Platform Kit** (Crafting Table)

> [!WARNING]
> It only fills empty air and does not work below the band, where the envelope would cook, or above it, where it would not lift.

> [!TIP]
> Hunt cloud jellies for their lift gas sacs, craft the kit and set up your base in the clouds. Wear acid-coated armour.

### Venus descent probe

**Venus Descent Probe**

The surface (464 °C, 92 bar) is closed to people. Release a **Venus Descent Probe** from the cloud deck, an aerostat base for example: it sinks under its parachute, and at touchdown it sends you **2 Venus samples** and **Probe Landing** data, then falls silent from the heat within about a minute.

|   |   |   |
|---|---|---|
|   | Envelope Fabric |   |
| Aerogel | Basic Circuit | Aerogel |
| Tungsten Ingot | Tungsten Ingot | Tungsten Ingot |

→ **Venus Descent Probe** (Crafting Table)

> [!WARNING]
> It can only be released on Venus from the cloud deck (y ≥ 175); lower down or anywhere else it is not used up. The samples go into your inventory, or drop at your feet when it is full. If you are offline when the probe lands, they do not arrive.

> [!TIP]
> Cloud jelly → aerostat kit → base in the clouds → descent probe → Venus samples → Venus technologies.

> [!NOTE]
> A derelict research balloon floats above the cloud tops. Its lab still holds tech disks, guarded by acid rays.

### The balloon's puzzles
- There are three **gas valves**; only the one marked **sulfur yellow** opens the gondola door.
- The gangway has a **falling floor** trap; the net below catches you.
