# Yörüngeler

*İlgili araştırma: Yörünge Mekaniği*

![](images/orbit.png)

Yörüngede hâlâ **düşüyorsundur**; ama yana öyle hızlı gidersin ki zemin altından kıvrılıp uzaklaşır.

| | |
|---|---|
| Alçak Dünya yörüngesi hızı | ≈ 7,8 km/s |
| Fırlatma maliyeti (kayıplarla) | ≈ 9,4 km/s Δv |
| Ay'a geçiş | ≈ 4,0 km/s Δv |

> [!NOTE]
> Aradaki fark **sürtünme** ve **yerçekimi kayıplarıdır**: atmosferden geçerken ve dik tırmanırken harcanan Δv.

→ Ayrıntısı: [Yörünge Nedir?](sci_orbit), [Transfer Yörüngeleri](sci_transfers)

<details>
<summary>English: Orbits</summary>

*Related research: Orbital Mechanics*

![](images/orbit.png)

In orbit you are still **falling**, but moving sideways so fast that the ground curves away beneath you.

| | |
|---|---|
| Low Earth orbit speed | ≈ 7.8 km/s |
| Launch cost (with losses) | ≈ 9.4 km/s Δv |
| Transfer to the Moon | ≈ 4.0 km/s Δv |

> [!NOTE]
> The difference is **drag** and **gravity losses**: Δv spent pushing through air and climbing straight up.

→ More: [What Is an Orbit?](sci_orbit), [Transfer Orbits](sci_transfers)

</details>
