# Hologram Projektörü

Büyük yapıları kurarken nereye ne koyacağını gösterir: yapı, dünyada **yarı saydam bir hologram** olarak belirir.

|   |   |   |
|---|---|---|
|   | Ametist Parçası |   |
| Redstone Tozu | #c:glass_panes | Redstone Tozu |
| Demir Külçesi | Bakır Külçesi | Demir Külçesi |

→ **Hologram Projektörü** (Çalışma Masası)

### Kullanım
1. Projektör elindeyken `Sağ Tık`: **plan listesi** açılır. Bir yapı seç.
2. Bir bloğa bakıp `Sağ Tık`: hologram o bloğun yanına yerleşir.
3. `Shift` + fare tekerleği: hologramı **döndür**.
4. `Shift` + `Sağ Tık` (havaya): **katman katman** göster. Alttan başla, her katmanı bitirince sonrakine geç.
5. `Shift` + `Sağ Tık` (bir bloğa): hologramı **kaldır**.

> [!TIP]
> Bu kitaptaki 3B yapıların altındaki **Hologramı göster** düğmesi, o yapıyı elindeki projektöre doğrudan yükler.

Eksik ya da yanlış bloklar hologramda görünmeye devam eder. Yapı tamamlanınca bir mesaj gelir.

→ **Hologram Projector** (Crafting Table)

### How to use it
1. `Right Click` with the projector in hand: the **blueprint list** opens. Pick a structure.
2. `Right Click` on a block: the hologram is placed next to it.
3. `Shift` + mouse wheel: **turn** the hologram.
4. `Shift` + `Right Click` (in the air): show it **layer by layer**. Start at the bottom and move on when a layer is done.
5. `Shift` + `Right Click` (on a block): **remove** the hologram.

> [!TIP]
> The **Show hologram** button under the 3D structures in this book loads that structure straight into the projector in your hand.

Missing or wrong blocks stay visible in the hologram. A message tells you when the structure is complete.
